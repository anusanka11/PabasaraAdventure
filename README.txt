# Pabasara Adventure Park Website

A responsive, lightweight static website for Pabasara Adventure Park, Sigiriya, Dambulla.

## Files
- index.html — main website
- style.css — responsive styling
- script.js — mobile menu, program detail modal and small reveal animations
- assets/hero.jpg — optimized version of the supplied Pabasara Adventure Park artwork

## Customize
The four instructor cards are intentionally written as placeholders:
Training Instructor 01–04. Replace their descriptions with actual qualifications,
experience and photos when those details are available.

The program descriptions are editable in `index.html`.

## Run
Open `index.html` in any modern browser. No server or framework is required.
